# Synthetic software example

Every score, endpoint and Gate label here is invented for software demonstration.
These records exercise software behavior with synthetic values. Eight unique simple
SMILES are used; Top3 is selected per model. SYN003 has a missing PharmacoNet
score and SYN006 has a missing ADMET endpoint. Both must remain pending.
The other four union candidates have complete scores. D1 and C1 are retained for
route follow-up but must not be treated as deliverable-now.

Use `configs/hdac2.json` for the real Top1000 profile and externally produced inputs.
